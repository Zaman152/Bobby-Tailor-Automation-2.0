<objective>
Wire the existing, tested keynote-callout detector into the floor-plan path, so a keynote
placed N times publishes as a flagged count of N with the note's own text as anchor.

Purpose: the first paid run of the post-28 engine predicted "Ladder-H-20' = 1, PASS expected"
(DEPLOYMENT-READINESS §6) and published NOTHING — because the detector that produces exactly that
answer has no caller on the plan path. This is a wiring gap, not a detection gap, and it is the
cheapest remaining conversion of a blank into a number anywhere in the program.

Generalization is the point, not a side constraint: the route reads whatever keynote legend any
sheet defines (keynote_legend), counts whatever bubbles that sheet draws (cluster_symbols), and
anchors on whatever text that legend prints. Nothing in it knows Crow.
</objective>

<tasks>

## T-29-03-01 — Adapter: KeynoteCallout → SymbolGroup

One SymbolGroup per keynote number with callouts > 0: count = callout count (legend bubble already
subtracted by the detector), contained_texts = [note text], needs_review = True, candidate_id
"KEY-<n>". Mirror `_lattice_as_symbol_group`'s shape exactly.

## T-29-03-02 — The spec-note guard (the §10 trap, named)

A note whose text matches the universal-quantifier shape (\bALL\b, \bTYP(ICAL)?\b, PROVIDE...AT)
is a SPECIFICATION; its placement count means nothing. Crow note 13 — "PROVIDE BOLLARDS AT ALL
DRIVE-IN OVERHEAD DOOR JAMBS..." — with one callout would publish Bollards = 1, which is WORSE
than today's honestly flagged blank. Such notes are excluded from the adapter, with the exclusion
logged. The Bollards blank stays a blank.

## T-29-03-03 — Suppress the aggregate bubble group

When per-number callout groups are emitted, the source bubble group they were split from is
dropped from `symbols` (it is annotations, not objects). Same drawn-once-published-once contract
as lattice shadowing, asserted by test.

## T-29-03-04 — Wire at the lattice injection point

After the lattice block (~3091): plan-sheet types only, additive, any failure leaves `symbols`
untouched. Log what was emitted and what was excluded.
