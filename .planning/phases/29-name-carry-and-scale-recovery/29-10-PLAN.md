<objective>
Give the run a reasoning pass that spans sheets and repeats until it stops learning, so a fact
printed on one sheet can answer a question raised on another — and so every question it still
cannot answer is handed to the client as a specific, actionable request.

Purpose: the pipeline is one-directional and per-sheet. Extract → fuse → aggregate → report, with
nothing reasoning over the assembled evidence. A door schedule on A-601 and a general note on
A-101 never meet, so a quantity the drawing states plainly across two sheets is unreachable.

The deliverable is TWO outputs, and the second matters as much as the first:
  1. quantities derived from linked cross-sheet evidence, flagged, each citing both sheets;
  2. an INPUT GAPS report — every unmet need, and every cited-but-absent sheet with the questions
     it would have answered. The client is not being told "we failed"; they are being told
     "send A-111, A-112, A-113 and the Stairs count becomes available".
</objective>

## T-29-10-01 — The Need

`Need(kind, subject, wanted, asked_by_sheet, evidence_text, blocking_item)`. Kinds, each already
produced somewhere today:

| kind | raised by | wanted |
|---|---|---|
| `referent_count` | 29-06 rule whose referent nothing counted | a count of the referent |
| `absent_sheet` | `missing_referenced_sheets` | the sheet itself |
| `unnamed_geometry` | ledger rows with a count and no name | a name |
| `hypothesis_name` | rows whose name is a hypothesis | printed confirmation |

Collected from the assembled run, never invented.

## T-29-10-02 — The resolver, ACROSS sheets

For one need, search EVERY sheet's evidence — schedules, legends, notes, counted symbol groups,
keynote text. Return zero, one, or many candidates.

- exactly one candidate → resolve, recording `answered_by_sheet` alongside `asked_by_sheet`
- zero → leave open
- **two or more → CLOSE AS UNRESOLVED naming every candidate.** Never arbitrate. 29-02 is the
  precedent and the reason.

## T-29-10-03 — The fixed-point loop

```
for round in 1..MAX_ROUNDS:
    resolved = [n for n in open_needs if resolve(n, evidence)]
    if not resolved: break
    evidence = extend(evidence, resolved)   # ADDITIVE ONLY
```

Terminates on a round that resolves nothing, or `MAX_ROUNDS` (a stated constant, logged when hit).
The loop exists because resolutions compound: a referent counted in round 1 can satisfy a rule that
was open in round 1 and resolvable only in round 2. A test drives exactly that two-round case, and
another asserts a no-op run leaves the take-off byte-identical.

`extend` may only ADD evidence. It may not replace a measured quantity, rename an
authority-named row, or raise a confidence. Asserted directly.

## T-29-10-04 — The INPUT GAPS report

For each unmet need: what was wanted, which sheet asked, the evidence text that raised it, and what
would answer it. For an `absent_sheet` need, group every question that sheet would have answered
under the sheet name, so the client gets one line per missing sheet with its consequences attached.

Published in the run artifacts beside `coverage.json`, and surfaced in `summary.txt`.

## T-29-10-05 — Tests

- a need raised on sheet A resolved by evidence on sheet B, citing both
- the two-round compounding case (single pass provably insufficient)
- termination: a cyclic/unsatisfiable need set stops at `MAX_ROUNDS` and logs it
- ambiguity: two candidates → UNRESOLVED naming both, no quantity
- additive-only: a measured quantity, an authority name and a confidence all survive a loop that
  touches their rows
- INERT: a run with no open needs produces a byte-identical take-off
- the absent-sheet report carries the QUESTIONS, asserted on Crow's real A-111/112/113 case
- NON-VACUITY: every assertion proved red before being kept
