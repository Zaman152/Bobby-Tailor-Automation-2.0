<objective>
Measure elevation facade area (gap 3, V4-MEAS-03) — the capability that makes a plan set with no
floor plan still produce quantities.

Purpose: elevations are structurally unreachable — the sheet type is absent from the deterministic
routing set, so the deterministic route is never called for one. Classification is NOT the bug; both
real elevation sheets classify correctly. And even if reached, nothing would measure: the only area
engine anchors on a plan-title pattern, and an elevation is titled differently. Forcing an elevation
sheet through the floor-plan path yields zero room fills anyway — and twenty-two FABRICATED walls
across four bogus thickness classes, which is exactly what a prior phase deliberately closed.

The right primitive is NOT the void flood fill. A facade is a filled silhouette subdivided by joint
and reveal lines; the void fill fragments one real facade into sixty-three pieces. Complement
labelling — flood the free pixels from the clip border, invert, take the largest component — returns
one clean blob per elevation on all three fixtures that have them, with no tuning.

Validation is by POSITION against independent measurements: facade blob widths match the floor plan's
independently measured footprint dimensions, and on one fixture the silhouette sum and the
perimeter-times-datum-height route agree to one percent between two measurements sharing no code path,
no sheet and no scale.

Output: the facade primitive, elevation titles and datums, the routing change with its negative test,
the binder, and the keynote-based material attribution with an honest split boundary.
</objective>
