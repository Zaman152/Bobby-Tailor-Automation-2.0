<objective>
Bind measured room geometry to wall-area line items (V4-MEAS-01), refactor the fusion gate into a
basis-to-binder registry with one-area-one-item arbitration (SP-9), and make the unit multiplier
visible and cross-checked (SP-10, V4-MEAS-02).

Purpose: one frozenset drops every wall-area object at the gate before any fill is looked at, so
ceiling binds and wall does not. Even with the gate opened there was nothing to bind until plan 23-09
gave a fill its perimeter. Four separate investigations independently proposed adding a FOURTH
parallel frozenset beside the existing one — the registry is what stops that (D-03).

Two landmines must be defused in the SAME change as the binder, not after it (R5). First, the
aggregator SUMS same-named buckets and the fusion entry point appends every binder's output into one
list with no deduplication, so the existing thickness-class wall figure plus a new room-fill figure
is a wrong number that looks better. Second, one measured footprint value on Crow is currently bound
to SIX line items at once — an estimator bidding from that report prices the floor six times.

Third, the wall height available today would poison this silently: the project resolver returns
fifteen feet harvested from a single clearance callout on a ROOF plan, and because its source is not
the default nothing flags. The real guest-room height is printed inside every prototype drawing.

Output: the perimeter and height primitives, the registry, the arbitration, and honest multiplier
provenance.
</objective>
