<objective>
Close the flagged-zero contract (SP-8, second half): make every one of INV-08's fifteen silent-drop
paths leave a record, make `quantity` an `Optional[float]`, and make flag-don't-guess real.

Purpose: `aggregator.py:435` ships the defaultdict's `0.0` for a `manifest_missing` row, so every
numeric consumer reads a blank as a zero (INV-08 §1.5). Four of the drop paths — `fusion.py:1540`,
`:1554`, `:1559`, `room_fill.py:140` — discard a **successfully measured** area, and `fusion.py:1559`
`continue`s exactly where `select_fill_for_basis`'s own docstring says the caller "must flag, never
substitute". Without this, every later plan's honest-failure branch has nowhere to write.

Output: drop records on the bundle, `quantity: Optional[float]`, per-row `provenance` and `measured`,
the flag-don't-drop repair in the selector and the binder, and a repaired `scripts/room_probe.py` that
finally exercises the fill engine.

Scope note: the REPORT-SIDE surfacing of all this — the four new report fields, `coverage.json`, the
`summary.txt` COVERAGE section, the CSV column and the workbook sheet — is plan 23-17, which runs in
the same wave and shares no file with this plan. The split is deliberate: every wave from 3 onward
depends transitively on this plan, so it is kept inside its context budget rather than carrying the
reporter work as well.
</objective>
