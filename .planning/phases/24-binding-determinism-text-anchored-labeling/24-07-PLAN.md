<objective>
Deliver the anchor to the model, and make topological gaps unexpressible by schema.

Purpose, part one (V4-DET-01's prompt half): `overlay._draw_marker` draws exactly two things per
candidate — a coloured rectangle and a chip whose text is `label = candidate_id`
(overlay.py:110). Nothing else. The model receives a box and an identifier string and is asked
to match it to a legend label. That is the symbol-conveyed condition the evidence base measures
at 0.03-0.39 accuracy against 0.65-0.92 for text-anchored classes. Changing that one line to
carry the anchor computed in plan 24-01 is the single highest-leverage edit in the requirement.

Purpose, part two (V4-DET-03): `semantic_labeling_schema` (schemas.py:52-95) is FLAT —
`main_plan_region` and `wall_class_labels`, with rooms labelled by a separate path and no
expressible relationship between a room and the walls bounding it. The observable consequence
in both saved runs: four room candidates published at roughly 10-11 SF each on a 397,600 SF
warehouse. FloorplanVLM's technique — define the wall skeleton first, express rooms as
references to it — makes an unbounded sliver unexpressible rather than merely flagged.

**A stale-prompt defect to fix while here.** `SYMBOL_GALLERY_PROMPT` (prompts.py:370) still tells
the model "The images form a crop gallery: each tile shows one symbol group... A crop of the
sheet's legend may be included." The pipeline migrated to in-context Set-of-Mark on the FULL
plan at takeoff_pipeline.py:3700-3709; the model now receives the whole drawing with markers on
it. The prompt describes images that are no longer sent. Correcting it is squarely in this
requirement's scope and cannot be deferred, because plan 24-09's fixture keys hash this exact
prompt text.

**Correction to the research's Wave 0 list.** 24-RESEARCH names `tests/test_schemas.py` and
`tests/test_overlay.py` as missing modules. They are not needed: `tests/test_vision_schemas.py`
already exists and already covers BOTH surfaces — schema numeric-field absence, candidate-ID
enum equality, the Set-of-Mark 40-marker budget and the pixel-to-point round trip. Extend it.
Creating two new modules would split one contract across three files.

**Hard constraint.** No numeric field may be added to any vector-path schema. The dependency
ordering adds STRUCTURE, not numbers. `raster_extraction_schema` remains the only schema
permitted numeric properties, and it is the flagged raster-fallback path.

**Sequencing warning.** This plan changes prompt text and schema shape. Every replay fixture key
is a SHA256 over the prompt, so plan 24-09 MUST author its fixtures after this lands. That is
why 24-09 is last.

Output: an anchor-bearing marker chip, an anchor table in the user hint, a dependency-ordered
schema, a corrected symbol prompt, and tests in the module that already owns both surfaces.
</objective>
