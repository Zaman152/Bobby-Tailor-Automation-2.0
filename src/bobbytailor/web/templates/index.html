How to use Bobby Tailor

        
Four minutes, and the report stops being cryptic.

      

        
The promise
          
No confidently wrong numbers. Every row is either a quantity measured off the
          drawing, or a visible blank that says why. The app leaves a cell empty rather than guess
          it. A blank costs you thirty seconds; a wrong number costs you a bid.


        
The six row states

          

            
✓ Measured
                Measured off the drawing. No human has confirmed it yet.

            
! Needs review
                Measured but flagged. Confirm it before you bid it.

            
∅ Not measured
                No measurement path on these drawings. A blank, not a zero — type your own.

            
– Not applicable
                The set genuinely contains none of these.

            
≡ Standard item
                A convention the app injects, e.g. Mobilization.

            
✎ Human input
                You typed it. Labelled as yours, permanently.

          

        


        
Writing a manifest

          
Your standard item catalog — reusable on every job.

          
[
  {"name": "Doors-STL", "unit": "EA", "measure": "count",
   "aliases": ["Doors - Steel", "steel door", "STL door"]},
  {"name": "CMU Wall", "unit": "SF", "measure": "area",
   "aliases": ["cmu", "concrete masonry", "block wall"]}
]

          
    
            
  • Aliases do the work — every way a drafter might write the item.
    • 
            
  • Your whole catalog, not this building's items. The same file should run on every job.
    • 
            
  • Never quantities. It is not a take-off.
    • 
            
  • Qualify one-word aliases. A bare "panel" once priced a
              tilt-up concrete panel as an electrical panel.
    • 
          

        


        
Calibrating

          
This is where a take-off gets finished.

          
    
            
  1. Tick Show only rows needing me.
    2. 
            
  2. Read the “Why” column first — it usually tells you exactly what to check.
    3. 
            
  3. Click the quantity and type your number. It publishes as HUMAN INPUT.
    4. 
            
  4. If it says NOT reconciled by name, add an alias to your manifest — that fixes it forever.
    5. 
            
  5. If it says NOT_IN_UPLOADED_SET, the answering sheet is missing. Upload it.
    6. 
          

        


        
Do not
          
Read a blank as a zero · quote the coverage percentage as an accuracy percentage ·
             upload a completed take-off as plans.
